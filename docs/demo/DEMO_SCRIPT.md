## 完整版（4:57）

### 0:00–0:13 开场

**画面**：对话页落地，左侧“最近会话”，顶部“代理律师 / 律师助理”，右上“监控 →”，右下免责声明。

**旁白**：
> 这是婚姻家事法律咨询 Agent。左边是会话历史，顶部可以切换代理律师和律师助理两种模式。

**操作**：关闭免责声明，鼠标掠过模式切换。

---

### 0:14–1:43 人机协同（HITL）

**画面**：输入家暴离婚问题 → 系统不直接回答，弹出琥珀色“案情澄清”卡片，带 A/B/C/D 选项。

**演示问题**：
> 我丈夫长期家暴，我想离婚，孩子3岁，房子是婚后买的，我能争取抚养权和房子吗？

**第一张卡（0:31）**：问家暴证据，选项为报警记录/聊天照片/暂无/其他。选 A 后提交。

**第二张卡（1:05）**：问对方对离婚和抚养权的态度。选 A 后提交。

**旁白（0:14）**：
> 先看人机协同。用户提出一个涉及家暴的离婚问题，系统先做风险与要素评估，不急着给结论。

**旁白（0:31）**：
> 要素缺失时，Agent 主动中断流程，把问题变成可选项交给律师。这里问的是家暴证据，选择后继续。

**旁白（0:57）**：
> 系统继续补齐关键事实：对方对离婚和抚养权的态度。

**旁白（1:06）**：
> 第二轮确认后，补充事实写回会话状态。所有中断都落在图状态里，回答后从断点继续，不用从头再跑。

**要点**：这一步展示的是 `interrupt()` + checkpoint 的“暂停—补充—续跑”，不是前端假装等待。

---

### 1:46–4:43 完整执行链

**画面**：新建会话，输入完整案情，进入 planner，右下状态栏依次出现“思考中 → 输出中 → 正在调用工具 → 质量门控 → 组装最终回答”，对话气泡下方自动展开“思考过程”。

**演示案情**：
> 我和丈夫2018年5月登记结婚，2020年3月生了一个儿子。他长期家暴，2025年6月我报警并搬走，现在分居。我想离婚，孩子由我抚养，他每月付3000元抚养费，婚后买的朝阳区房子登记在双方名下、贷款共同还，要求依法分割。我有报警记录、告诫书、伤情照片、医院诊断、房产证、贷款合同、孩子出生证明和微信聊天记录。他现在不同意离婚，也不同意孩子归我，说房子要留着自己住。

**计划（约 1:51）**：5 步——检索判例、评估相关性、检索法条、法律分析、写入长期记忆。

**旁白（1:46）**：
> 接下来走完整链路。把案情、诉求、证据一次给全，系统进入规划：检索判例、评估相关性、检索法条、法律分析、写入记忆。

**工具执行（约 2:11）**：`retrieve_legal_knowledge` → `evaluate_case_relevance` → `fetch_laws` → `analyze_legal_issue` → `save_to_memory`。

**旁白（2:11）**：
> 执行阶段用轻量模型逐步调用工具。第一步是 RRF 混合检索：稠密语义和 BM25 关键词两路召回，融合后交给 CrossEncoder 重排。

**旁白（2:40）**：
> 界面实时显示计划、工具调用和思考过程。检索结果不直接当答案，而是先做三档质量评估：相关、模糊、不相关。

**旁白（3:20）**：
> 资料不足时系统会重规划并联网补充；这次判例相关度足够，继续做法条检索和法律分析。

**旁白（4:00）**：
> 最后做质量门控和答案组装。整个过程不是黑盒，节点、工具和模型输出都有时间轴记录。

**要点**：状态栏、步骤进度、工具时间线、CoT 都是真实 SSE 事件驱动，不是预置动画。

## 90 秒投递版（如需要，按此重录或剪辑）

适合简历附件 / 初面自我介绍，只保留三个镜头。

**0:00–0:12 定位**
> 这是一套面向婚姻家事咨询的法律 Agent，不是问答 Demo：后端是 LangGraph 的 16 节点 Plan-and-Execute，前端可以把推理、工具调用和人工确认全过程实时展示出来。

**0:12–0:40 人机协同**
> 法律场景不能全自动。要素缺失、高风险、出文书都需要律师拍板。系统用 interrupt 加图状态检查点做了 8 类中断，回答后从断点继续，不用从头再跑。

**0:40–1:20 检索质量**
> 检索不是把向量相似度当相关性。我们用 RRF 融合稠密和 BM25 两路召回，再用 CrossEncoder 重排出绝对分，三档阈值拿 30 条真实案例标定过。资料不够就明确降级去联网，不硬答。

**1:20–1:30 收尾**
> 我的工作是把 LLM 的不确定性，收敛成律师可验收的流程。这套方法可以复用到合同审查、理赔等有 SOP、有验收标准的场景。
